# PawFind

Image-based product search project for a pet shop web application.

## Mục tiêu

Xây dựng mô hình tìm kiếm sản phẩm bằng hình ảnh để phục vụ tính năng tìm kiếm trong webapp shop thú cưng.

## Trạng thái dự án

- Giai đoạn: Setup ban đầu (pre-alpha)
- Chưa có code huấn luyện
- Chưa có thử nghiệm
- Chưa chọn model cuối cùng

## Phạm vi hiện tại

- Thiết lập môi trường làm việc
- Xác định bài toán image-based product search
- Chuẩn bị nền tảng cho bước chọn baseline model và chạy thử nghiệm đầu tiên
